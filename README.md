## 🛠️ Quickstart Local Setup

```bash
# 1. Clone repository
git clone https://github.com/Shaikshadik03/BuildWithShadik-Ai-Agency.git

# 2. Enter project folder
cd BuildWithShadik-Ai-Agency

# 3. Install packages
npm install

# 4. Fire up the local dev server
npm run dev

# 5. Build for production
npm run build
```
